CSV Format

Required columns:

  • username User's username or email
  • shift_name Name of the shift to assign
  • start_date Start date (YYYY-MM-DD format)

Optional columns:

  • end_date End date (YYYY-MM-DD format)
  • notes Additional notes or comments

Sample Data

username shift_name start_date end_date notes
john.doe Morning Shift 2024-01-01 2024-01-31 January assignment
jane.smith Night Shift 2024-01-01 Ongoing assignment

Upload Guidelines

Ensure all usernames exist in the system

Verify shift names match existing shifts exactly

Use YYYY-MM-DD format for all dates

Leave end_date empty for ongoing assignments

Maximum file size: 10MB

Use "Validate only" option to check for errors before importing
